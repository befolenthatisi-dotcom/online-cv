# My Online CV
A professional online CV presenting my profile, education, technical skills, experience, academic projects, and references.

## Features

- Personal profile and contact information
- Education background
- Technical skills
- Experience
- Academic projects
- Professional and academic references
- Dark and Light Mode
- Show and Hide References
- Print CV
- Active navigation
- Responsive design for desktop, tablet, and mobile devices

## Technologies Used

- React.js
- JavaScript
- JSX
- CSS
- HTML

## React Concepts Used

The project demonstrates:

- Functional Components
- JSX
- Props
- Component Composition
- useState
- useEffect
- Event Handling
- Responsive CSS

## How to Run the Project

1. Clone or download the project.
2. Open the project folder in a terminal.
3. Install the required dependencies:

  ---bash
  npm install

4. Start the application:

   npm start

5. Open the application in your browser.
